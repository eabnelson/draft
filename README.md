# Draftroom origins

The source transcript and initial product specification behind **Writing Room**, the first local version of the writing editor later developed as **Draftroom**.

## Original video

[Jason Fried’s writing-editor demonstration on X](https://x.com/jasonfried/status/2105403067793584590).

- Creator: Jason Fried
- Duration: approximately 6 minutes 55 seconds
- Source post: `2105403067793584590`

## Full transcript

The complete saved transcription is preserved in three formats:

- [Timestamped transcript](sources/transcript.md)
- [Plain-text transcript](sources/transcript.txt)
- [Structured transcript with all 120 timed segments](sources/transcript.json)

These files are unchanged copies of the transcript generated by [toscript](https://github.com/eabnelson/toscript) for the original build. The English audio was transcribed locally using `mlx-community/whisper-large-v3-turbo`. This is an automated transcript and has not been manually corrected. The source video and spoken material are credited to Jason Fried.

## Initial product spec

[Read the original product spec — Draft v0.1, October 22, 2026](docs/initial-product-spec.md).

This is the exact initial specification used to build the local Writing Room app. It records the demonstrated behaviors, proposed P0/P1 scope, acceptance criteria, data model, privacy defaults, open decisions, and implementation order. It has been preserved without incorporating later UI changes or Zo integrations.

The spec was authored for this project from the demonstration. Its proposed requirements are separate from statements made in the video.

Original Studio Four record: [Writing Editor Product Spec Draft](https://studiofour.io/artifacts/c3765ad8-c6c0-4ea1-86d8-65d89dc8367d), version `d2c948e6-ebd5-41a5-88d4-17ec833dae3a`.
