# Draft landing page

A static page with Draft’s origin, build story, download, and usage flow. It uses the app’s existing logo and has no dependencies, scripts, or tracking in the page.

From the repository root:

```sh
bun run website:dev
```

Open http://127.0.0.1:4320/. You can also open index.html directly or serve this folder with any static server. No hosting service is configured.
